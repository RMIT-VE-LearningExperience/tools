Canvas Image Block Generator

Crop an image to the shape you need, download it ready to upload to Canvas, then build the matching Emble block with a correctly formatted credit line. The block arrives with a placeholder for your cropped image.

1

Crop the image

The file stays in your browser. Nothing is uploaded anywhere.

Drop an image here or click to choose one JPG, PNG or WebP

Drag inside the box to move it, drag a corner to resize.

Around 1200 suits a full width image, around 800 suits a column image. Smaller files load faster for students.

Cropped result. If the download does nothing in a preview window, right click this image and save it.

Upload the downloaded file to Canvas Files, then replace the placeholder in the generated block with it. Canvas writes the alt text for you when you insert the image.
2

Image credit

Paste what the source gives you. The wording is assembled to the RMIT standard.

On the Unsplash download screen choose the copy credit option, then paste the whole line here. Either format works, the HTML one Unsplash copies or a plain markdown one. The licence sentence is added for you.

Right click the image itself on the Adobe Stock page, choose copy image address, then paste it here. The asset number is read out of the address. The address of the Adobe Stock page also works if you have that instead.

Right click the contributor name that sits under the image title, choose copy link address, then paste it here.

Read from the address, so it arrives in lower case. Correct the capitalisation here if it needs it.

Nothing to enter. The standard RMIT content drop credit line is used.

Plain text is fine. Links written as [text](address) are converted for you.

Credit line as it will appear
3

Layout and text

Choose how the image sits against the text in the Emble columns block.

Leave this empty and the block keeps the highlighted Text goes here placeholder. Blank lines start a new paragraph.

4

Canvas HTML

Open the Canvas page editor, switch to the HTML view, place the cursor where the block belongs and paste. Then switch back, select the placeholder line and replace it with your uploaded image.
