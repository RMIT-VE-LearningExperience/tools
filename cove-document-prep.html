CoVE Document Prep

Prepares Word documents for an AI session. Resolves Word automatic numbering into literal numbers that survive upload, and reports how much document there is — so you can tell whether the assistant read all of it. Works on any .docx; documents built on the VE assessment template also have their unit code and task number read out of the header table.

How to use what this produces

  • Upload the flattened .md file in place of the .docx. Question and item numbers are written into the text, so they cannot be lost on extraction.
  • Keep the reference card on screen while the session runs. When the prompt states the last item it can see, compare it with the last item listed here. If they differ, the upload was truncated — start a fresh chat.
  • Flattening is not a substitute for the guard. It removes the most common cause of a bad read; the extent check is what catches the rest.
  • Formatting, colour and page layout are deliberately dropped. These tools judge instructions and evidence, not appearance.
  • Identifiers are read from the VE assessment template only. If a document isn't built on that template, everything else still works — you'll just be asked for the task identifier yourself.
