Quiz rubric CSV

For knowledge tasks that students complete in a template and submit. Reads the questions out of the student version of the task and writes a Canvas rubric import CSV with one criterion per question. It only reads. Your document is not changed and nothing leaves your computer.

1. Add the student version of the task

Drop the .docx here or click to choose. Use the student version, not the assessor guide, so no answers can end up in the rubric.

2. Check the questions


  


  

    
Each question becomes one criterion. The criterion name is the question number (Q1, Q2 and so on) and the long description holds the full question as the student sees it, including answer options, parts and table content. Pictures are shown as [image]. Every criterion gets two ratings: Satisfactory (1 point) and Not Yet Satisfactory (0).

    
Questions are found by their numbering: typed labels such as "1. Multiple choice", "Question 1" or "Q1", or Word's automatic numbered list. Numbers must run in order, so a numbered list inside a question is read as part of that question. Text in red or in the template's blue guidance colour is left out.

    
In Canvas: Course, Rubrics, Import Rubric, then attach the rubric to the assignment. Upload the downloaded file directly. It is UTF-8 with no byte order mark, which is what Canvas expects.
