How to Use This Tool

  1. Upload the Assessor Guide (.docx) containing quiz questions
  2. Review the automatically extracted questions, answers, and correct responses
  3. Edit any questions, options, or correct answers as needed. Questions flagged with ⚠ need your verification of the correct answer.
  4. Generate QTI 1.2 XML ready for Canvas import
  5. Download the .zip — the XML is zipped flat, ready for Canvas
  6. Import into Canvas: Settings → Import Course Content → QTI .zip File
💡
12 Question Types Supported: Multiple Choice, Multiple Answer, True/False, Matching, Fill in the Blank, Fill in Multiple Blanks, Multiple Dropdowns, Numerical Answer, Calculated/Formula, Essay, File Upload, and Text Only.
⚠️
Verify-answer flag: If a question's correct answer can't be clearly identified from the source doc, the question will show a yellow ⚠ badge in Review. Click the badge to dismiss after verifying, or just set the correct answer and the flag clears automatically.
