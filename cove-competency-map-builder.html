CoVE Competency Map Builder

Fills the Competency Assessment Map template from the unit's benchmark codes and each task's Quick Check summary. Unit wording is copied exactly; locations are copied exactly from the reads. Nothing is judged here — anything that doesn't line up stops the build and is listed below.

1. Add files

Drop the flattened unit (.md) from Document Prep and the Quick Check reads (.txt or .md — the Collector file or one file per task). Flattened assessor guides are optional: they only prefill the details below. The competency map template is built in; drop a .docx only to use a different version.

2. Check

Add files to see what was recognised.

3. Map details

Task rows appear once the Quick Check reads are added.

4. Result

How the map is filled

  • Requirement text comes from the unit file, word for word. Parent items ("…including:") appear as shaded heading rows; their sub-items sit beneath.
  • Task cells: FULL → the location exactly as the read records it; PARTIAL → the location plus “(partial)”; NEAR-MISS → the location in a Knowledge task (the column says it's knowledge), “—” in any other task; NONE → “—”.
  • Task columns are added or removed to match the number of tasks. Titles, method ticks, qualification and program code come from the Map details you enter (guides, if added, prefill them).
  • One template property changes: the Element and Performance Criteria table is set to in-line (the template has it floating), because a floating table can't run safely across pages.
  • Locations are written as Q16–Q17, Q31 for questions and OT1; OT4–OT13 for observation tasks (Practical tasks only). Anything that doesn't parse is copied exactly.
  • Highlighted template instructions are removed, along with the Instructions heading.
  • Left for a person: date, mapper, approver, elective/core, and the “how met” column of the assessment conditions table.
  • Hard stops: a read whose codes, order or row count differ from the unit's benchmark codes; a read missing END; two reads for the same task; a read for a different unit.
