How to use this tool

Everything students see is built from the student guide, so Canvas matches the Word version on SharePoint.

  • Student guide → Canvas page HTML for every type, and the Canvas rubric CSV for Practical, Product and Knowledge Submission tasks. Section A and the criteria go across word for word.
  • Assessor guide → QTI 1.2 quiz. Required for quizzes, because only it has the answer key. Optional for other types: load it to check the student version against it.
ℹ
With both loaded, the tool checks they are the same task and the same version: unit code, task number and type, and every question or criterion. If they don’t match, nothing is generated — one of them is out of date.
⚠
Answer keys and minimum requirements never leave the assessor guide. The student guide is also checked for red text, answer lines and Minimum Requirement wording before its content is used.

Nothing from either guide can be edited here. If something is wrong, talk to your Quality Lead, fix the Word document and re-run — the documents stay the single source of truth.
