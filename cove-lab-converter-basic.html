How to Use This Tool

  1. Paste the Part B output from the lab activities prompt
  2. Review the parsed activities, steps and image markers
  3. Edit any fields that need correction
  4. Check the counts in the output panel
  5. Generate your Canvas-ready Emble HTML
💡
Tip: The parser reads ──── Activity 1: Title ──── sections. Numbered lines become steps, [IMAGE: ...] lines become teacher placeholders, and a Download: line becomes a yellow file placeholder. Use "Load Sample" to test.

📄 Page Header

One instruction per line. Each becomes its own paragraph.

Appears under a bold "Important:" label. Leave blank to omit.

Sits beside the yellow target icon.

📝 Lab Activities

Each activity becomes one Emble colour block. Steps and image markers keep the order you enter them in.
