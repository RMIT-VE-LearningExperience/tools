Download all files from a Canvas page

One-off set-up, then one click on any Canvas page.

1. Add the button to your browser

  1. Show your bookmarks bar: Ctrl+Shift+B (Windows) or Cmd+Shift+B (Mac).
  2. Drag this red button up onto your bookmarks bar:
    ⬇ Download all
  3. Already have an older version? Delete the old bookmark first (right-click → Delete), then drag this one across.

2. Use it in Canvas

  1. Open the Canvas page with the files you want.
  2. Click ⬇ Download all in your bookmarks bar.
  3. A box in the bottom-right corner shows progress. You can Cancel at any time.
  4. When it finishes, the box tells you exactly what's in the zip. If any file couldn't be added, it lists them with links so you can download them yourself.

Good to know

  • Use it on a computer: Chrome, Edge, Firefox or Safari. It won't work in the Canvas Student app or on most phones.
  • It only downloads files you can already open in Canvas, using your own login. It doesn't store login details, run in the background or send anything outside Canvas.
  • Each zip can be up to 500 MB. If a page has more than that, you'll get links to download the files one at a time.
  • If some files are missing from the zip, it includes a "MISSING FILES" note listing them.
